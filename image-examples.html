Image Utility Examples

Basic Image Classes

Size Classes

Here are examples of different image sizes:

Small: .img-small - max-width: 200px

Medium: .img-medium - max-width: 400px

Large: .img-large - max-width: 600px

Full: .img-full - width: 100%

Position Classes

Left aligned: .img-left - Floats left with right margin

Right aligned: .img-right - Floats right with left margin

Centered: .centerimg - Displays as block with auto margins

Style Classes

Rounded: .img-rounded - 8px border radius

Circle: .img-circle - 50% border radius

Shadow: .img-shadow - Drop shadow effect

Border: .img-border - Border using accent color

Figure with Caption

Use <figure> and <figcaption> for images with captions:

<figure class="centerimg">
  <img src="/files/images/example.jpg" alt="Description">
  <figcaption>This is a caption</figcaption>
</figure>

Image Galleries

Create responsive image grids:

  • .image-gallery - Default grid (200px min columns)
  • .image-gallery-small - Small grid (150px min columns)
  • .image-gallery-large - Large grid (300px min columns)

JavaScript Helper Functions

Include /imageHelpers.js and use these functions:

Basic Functions

// Simple image
addImage('content/example.jpg', 'Description', 'img-medium centerimg')

// Figure with caption  
addFigure('projects/screenshot.png', 'Screenshot', 'My app screenshot', 'centerimg')

// Image gallery
addGallery([
  {src: 'content/img1.jpg', alt: 'Image 1'},
  {src: 'content/img2.jpg', alt: 'Image 2', caption: 'With caption'}
], 'medium')

Quick Shortcuts

// Common patterns
ImageShortcuts.leftSmall('content/diagram.png', 'Diagram')
ImageShortcuts.rightSmall('content/icon.png', 'Icon') 
ImageShortcuts.centerMedium('content/photo.jpg', 'Photo')
ImageShortcuts.hero('backgrounds/banner.jpg', 'Hero banner')
ImageShortcuts.avatar('content/profile.jpg', 'Profile photo')
ImageShortcuts.screenshot('projects/demo.png', 'Demo', 'App demonstration')

File Organization

Organize your images in these directories:

  • /files/images/content/ - Blog posts, articles, general content
  • /files/images/projects/ - Project screenshots and media
  • /files/images/icons/ - UI icons and small graphics
  • /files/images/backgrounds/ - Hero images and backgrounds
