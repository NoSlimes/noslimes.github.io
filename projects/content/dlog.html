DLog enhances the default Unity console with a flexible, color-coded category system and a dedicated, filterable log window. With support for developer-only logs that are stripped from builds, DLog helps you debug more efficiently without runtime overhead in production.

Features

  • Categorized logs with color coding (Log, Warning, Error, and custom categories)
  • Developer-only logs that are excluded from builds
  • Dedicated Editor Window for viewing logs in real-time with filtering options
  • Editor utilities for upgrading existing Debug.Log calls to DLog

Installing

You can add DLog to your project in two ways: via the Unity Package Manager (recommended) or by importing a .unitypackage.

Method 1: Unity Package Manager (Recommended)

This is the cleanest method, as it keeps the package separate from your Assets folder and makes updates easy.

  1. In the Unity Editor, open the Package Manager window (Window > Package Manager).
  2. Click the + (plus) icon and select "Add package from git URL...".
  3. Enter the following URL and click Add:
https://github.com/NoSlimes/DLog.git

Method 2: Traditional .unitypackage

  1. Go to the Releases page.
  2. Download the latest .unitypackage and import it into your project via Assets > Import Package > Custom Package....

How to Use

Simple Logging

Use the static methods in DLog to log messages:

DLog.Log("This is a standard log message");
DLog.LogWarning("This is a warning message");
DLog.LogError("This is an error message");

// Developer-only logs (only visible in the editor, not included in builds)
DLog.DevLog("Developer-only log");
DLog.DevLogWarning("Developer-only warning");
DLog.DevLogError("Developer-only error");

Opening the Log Console Window

  • In the Unity Editor: Window > DLog Console.
  • The window displays logs generated via DLog in real-time and can optionally fetch logs from Unity's built-in console.
  • Logs are color-coded by category and the window supports filtering options.

Creating and Using Custom Categories

1. Define Your Categories

Centralize your categories in a static class for easy reuse and consistency. Example:

using UnityEngine;
using NoSlimes.Logging;

public static class LogCategories
{
    public static readonly DLogCategory AI = new("AI", Color.cyan);
    public static readonly DLogCategory Networking = new("Network", "#FFA500"); // Orange
    public static readonly DLogCategory UI = new("UI", new Color(0.5f, 0.7f, 1f)); // Light Blue
}

2. Use Categories When Logging

using NoSlimes.Logging;

public class EnemyAI : MonoBehaviour
{
    void ChangeState(string newState)
    {
        DLog.Log($"State changed to '{newState}'", this, LogCategories.AI);
    }
}

Developer-Only Logs

Use DevLog, DevLogWarning, and DevLogError for messages you want to see only in the editor. These calls are automatically excluded from builds.

using NoSlimes.Logging;

public class PlayerMovement : MonoBehaviour
{
    void Update()
    {
        DLog.DevLog($"Player position: {transform.position}", this, LogCategories.Physics);
    }

    void OnCollisionEnter(Collision collision)
    {
        DLog.DevLogWarning("Player collided with an untagged object.", this, LogCategories.Physics);
    }
}

Upgrading Existing Projects

DLog Upgrader Utility

Warning: This tool modifies C# files directly. These changes cannot be undone. Back up your project or use version control before running the upgrader.

Open the upgrader in Unity via Tools > DLog Upgrader. The window will also prompt you after installation to encourage upgrading.

Workflow

  1. Click "Find All Debug.Log Occurrences" to scan your project and group results by file.
  2. Review each file and use per-file Upgrade to DLog or Upgrade to DevLog buttons, or use the global Upgrade All actions.

Manually converting all Debug.Log calls in a large project is tedious; the upgrader automates this process where possible.

Summary

DLog improves Unity debugging by providing structured, color-coded logs and a dedicated console. It is particularly useful for teams that want readable, filterable logs without shipping noisy debug output to players.
